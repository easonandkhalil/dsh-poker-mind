# 德州心法 · 快速牌局

在对话输入框下方点 **♠ 快速牌局**，打开 4 人桌。牌桌由 `shell.overlay` 以右侧浮动面板承载，左侧聊天仍可使用；关闭后当前牌局保留，下次继续。

## 这一版有什么

- 4 人桌（你 + 3 个从固定人设池随机抽取的 AI），100BB，1/2 盲注
- 翻前/翻牌/转牌/河牌；弃牌、过牌、跟注、加注、全下
- 每个对手显示位置、筹码、本轮下注；轮到谁行动有高亮
- 实时教练：胜率、底池赔率、补牌、SPR、范围估算、更优解；右侧拆解默认展开
- 亮牌结果：公共牌、所有人底牌、最终牌型、赢家与净值
- 战绩保存在本机浏览器（手数、胜场、净 BB）
- `Esc` 关闭牌桌；关闭不会弃掉当前手牌

## 这一版没有什么

- 没有 Android 版的牌局博物馆、24 位对手图鉴、100 手自画像
- 没有语音；DSH 版先保证随时能玩、能看教练
- 没有专家模式逐街复盘；结果页只给本手摘要
- 战绩只存在当前浏览器，和 Android 版不互通

## 说明

核心牌力、范围、胜率、AI 与教练逻辑复用自德州心法手机版；DSH 版重写了 React 牌桌外壳与交互。AI 不读取你的底牌，只根据公开行动、位置、筹码和范围估算行动。
